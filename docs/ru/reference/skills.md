# Skills

engram поставляется с шестью skills. В Claude Code они ставятся в `.claude/skills/` и становятся slash-командами; для остальных MCP-клиентов доступны как MCP prompts.

| Skill | Когда агент его использует |
| --- | --- |
| `remember-decision` | Принято решение или отвергнут вариант; «запомни это», «делаем так» |
| `recall` | «Мы уже…?», «где мы обсуждали…?», вход в незнакомую часть кода |
| `why-we-did-this` | «Почему X так устроен?», «почему не Y?», перед изменением устоявшегося паттерна |
| `avoid-past-mistakes` | Перед рефакторингом, миграцией, заменой зависимости, рискованными файлами |
| `project-summary` | Онбординг, «введи в курс дела», после перерыва |
| `session-handoff` | «Закругляемся», «сохрани прогресс», конец задачи |

## Пример: `remember-decision`

Записывает решение в фиксированной форме — *Контекст · Решение · Почему · Альтернативы · Последствия* — проверяет, нет ли более раннего решения для замещения, и сохраняет серьёзно рассмотренные альтернативы как `rejected`-решения со связью `rejected_because`.

## Пример: `avoid-past-mistakes`

Формулирует план, вызывает `engram_check` с планом и файлами, для каждого предупреждения решает, применимо ли оно, корректирует план или останавливается и спрашивает, а если что-то всё же выстрелило — записывает новые грабли.

## Свой skill

Skill — это папка с `SKILL.md`:

```markdown
---
name: release-checklist
description: Перед релизом вспомнить грабли и принципы релизов.
---

1. Вызови `engram_recall` с `kinds: ["pitfall", "principle"]` и `tags: ["release"]`.
2. …
```

`$ARGUMENTS` заменяется тем, что пользователь написал после команды.
