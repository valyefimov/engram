# Skills

engram постачається з шістьма skills. У Claude Code вони встановлюються в `.claude/skills/` і стають slash-командами; для інших MCP-клієнтів доступні як MCP prompts.

| Skill | Коли агент його використовує |
| --- | --- |
| `remember-decision` | Ухвалено рішення або відхилено варіант; «запам’ятай це», «робимо так» |
| `recall` | «Ми вже…?», «де ми обговорювали…?», вхід у незнайому частину коду |
| `why-we-did-this` | «Чому X так влаштований?», «чому не Y?», перед зміною усталеного патерну |
| `avoid-past-mistakes` | Перед рефакторингом, міграцією, заміною залежності, ризиковими файлами |
| `project-summary` | Онбординг, «введи в курс справи», після перерви |
| `session-handoff` | «Закруглюємося», «збережи прогрес», кінець завдання |

## Приклад: `remember-decision`

Записує рішення у фіксованій формі — *Контекст · Рішення · Чому · Альтернативи · Наслідки* — перевіряє, чи немає ранішого рішення для заміщення, і зберігає серйозно розглянуті альтернативи як `rejected`-рішення зі зв’язком `rejected_because`.

## Приклад: `avoid-past-mistakes`

Формулює план, викликає `engram_check` з планом і файлами, для кожного попередження вирішує, чи воно застосовне, коригує план або зупиняється й питає, а якщо щось таки вистрелило — записує нові граблі.

## Власний skill

Skill — це тека з `SKILL.md`:

```markdown
---
name: release-checklist
description: Перед релізом згадати граблі й принципи релізів.
---

1. Виклич `engram_recall` з `kinds: ["pitfall", "principle"]` і `tags: ["release"]`.
2. …
```

`$ARGUMENTS` замінюється тим, що користувач написав після команди.
