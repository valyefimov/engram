# CLI

```
engram <команда> [опции]
```

| Команда | Что делает |
| --- | --- |
| `init` | Создаёт `.engram/`, подключает агентов, ставит skills, индексирует репозиторий |
| `serve` (`mcp`) | Запускает MCP-сервер через stdio |
| `status` | Количество по видам и статусам, последняя активность |
| `summary [--full]` | Обзор проекта |
| `context [задача…]` | Печатает контекст-пакет, который получит агент (`-b` бюджет, `-f` файлы, `--raw`) |
| `remember <заголовок>` (`add`) | Сохраняет запись (`-k` вид, `-c` текст, `-t` теги, `-f` файлы, `-i` важность, `-s` статус, `--supersedes id`) |
| `recall [запрос…]` (`search`) | Ищет (`-k` виды, `-t` теги, `-f` файлы, `-a` с неактивными, `-n` лимит, `--json`) |
| `show <id>` (`get`) | Одна запись со связями (`--json`) |
| `link <from> <relation> <to>` | Связывает записи (`-n` заметка) |
| `graph <id>` | Показывает окрестность в графе (`-d` глубина) |
| `why <тема…>` | История темы |
| `check <план…>` | Сверяет план с граблями (`-f` файлы) |
| `forget <id>` | Архивирует, а с `--hard` удаляет |
| `index` | Импортирует ADR и сигналы из git (`--no-adr`, `--no-git`) |
| `export` | `--format jsonl` или `md`, `-o file` |
| `import <file>` | Вливает JSONL-выгрузку |
| `sync` | Перечитывает и начисто переписывает `memories.jsonl` |
| `skills list` | Показывает встроенные skills |
| `skills install` | Копирует skills в `.claude/skills` (`--global`, `--dir`) |

## Опции `init`

| Опция | |
| --- | --- |
| `-a, --agent <список>` | `claude`, `cursor`, `agents-md`, `all`. По умолчанию агенты определяются сами. |
| `-p, --project <имя>` | Имя проекта для обзоров |
| `--no-skills` | Не ставить skills |
| `--no-index` | Не сканировать ADR и историю git |

## Переменные окружения

| Переменная | |
| --- | --- |
| `ENGRAM_ROOT` | Принудительно задаёт корень проекта |
