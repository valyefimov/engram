# Дорожня карта

## v1.0 — пам’ять, яка працює ✅

- MCP-сервер: 14 інструментів, ресурси, prompts, інструкції сервера
- Сховище на SQLite + FTS5 (без нативних залежностей), дедуплікація
- Граф знань із типізованими ребрами, лінією рішень, `why`, перевіркою граблів
- Компресор контексту з бюджетом токенів, передача сесій
- Імпорт ADR, hotspots і відкати з git
- 6 skills, CLI, git-friendly синхронізація через JSONL з tombstones
- Документація англійською, російською та українською

## v1.1 — розуміння коду

- Індексатор коду (tree-sitter / ts-morph): символи як вузли `file`, пов’язані з рішеннями
- Опційні локальні ембедінги (bge / nomic) для гібридного пошуку
- Автоматична маршрутизація великих виводів інструментів
- Гігієна пам’яті: застарілі записи, чиї файли змінилися або зникли

## v1.2 — команди

- Кілька проєктів і особиста кросс-проєктна пам’ять
- Синхронізація не лише через git (опційний сервер)
- Веб-UI для перегляду й редагування графа

## v2.0

- Локальні ембедінги з коробки
- Інтеграції з популярними агентами однією командою
- Плагінна система для власних індексаторів і видів записів
