# Дорожная карта

Это планы. Сроки и состав могут измениться.

## 1.0: что есть сейчас

- MCP-сервер с 14 инструментами, ресурсами, prompts и инструкциями для агента
- Хранилище на SQLite и FTS5 без нативных зависимостей, с обработкой дубликатов при записи
- Граф знаний с типизированными рёбрами, линией решений, `why` и проверкой граблей
- Компрессор контекста с бюджетами токенов и передача сессий
- Импорт ADR, а также hotspots и откаты из git
- Шесть skills, CLI и синхронизация через JSONL с tombstones, удобная для git
- Документация на английском, русском и украинском

## 1.1: понимание кода

- Индексатор, который разбирает код (tree-sitter или ts-morph): символы как узлы `file`, связанные с решениями
- Необязательные локальные эмбеддинги (bge или nomic) для гибридного поиска по смыслу и по словам
- Маршрутизация больших выводов инструментов
- Поиск устаревших записей, чьи файлы изменились или исчезли

## 1.2: команды

- Несколько проектов и личная память, общая для них
- Синхронизация не только через git, через необязательный сервер
- Веб-интерфейс, чтобы просматривать и редактировать граф

## 2.0

- Настройка для других агентов одной командой
- Плагины для своих индексаторов и видов записей
