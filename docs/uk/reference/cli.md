# CLI

```
engram <команда> [опції]
```

| Команда | Що робить |
| --- | --- |
| `init` | Створює `.engram/`, підключає агентів, встановлює skills, індексує репозиторій |
| `serve` (`mcp`) | Запускає MCP-сервер через stdio |
| `status` | Кількість за видами й статусами, остання активність |
| `summary [--full]` | Огляд проєкту |
| `context [завдання…]` | Контекст-пакет, який отримає агент (`-b` бюджет, `-f` файли, `--raw`) |
| `remember <заголовок>` (`add`) | Зберегти запис (`-k` вид, `-c` текст, `-t` теги, `-f` файли, `-i` важливість, `-s` статус, `--supersedes id`) |
| `recall [запит…]` (`search`) | Пошук (`-k` види, `-t` теги, `-f` файли, `-a` разом із неактивними, `-n` ліміт, `--json`) |
| `show <id>` (`get`) | Один запис зі зв’язками (`--json`) |
| `link <from> <relation> <to>` | Зв’язати записи (`-n` нотатка) |
| `graph <id>` | Околиця в графі (`-d` глибина) |
| `why <тема…>` | Історія теми |
| `check <план…>` | Перевірити план на граблі (`-f` файли) |
| `forget <id>` | Архівувати або `--hard` видалити |
| `index` | Імпорт ADR і сигналів із git (`--no-adr`, `--no-git`) |
| `export` | `--format jsonl|md`, `-o file` |
| `import <file>` | Влити JSONL-вивантаження |
| `sync` | Перечитати й начисто переписати `memories.jsonl` |
| `skills list` | Вбудовані skills |
| `skills install` | Скопіювати skills у `.claude/skills` (`--global`, `--dir`) |

## Опції `init`

| Опція | |
| --- | --- |
| `-a, --agent <список>` | `claude`, `cursor`, `agents-md`, `all` (за замовчуванням — автовизначення) |
| `-p, --project <назва>` | Назва проєкту для оглядів |
| `--no-skills` | Не встановлювати skills |
| `--no-index` | Не сканувати ADR і git-історію |

## Змінні оточення

| Змінна | |
| --- | --- |
| `ENGRAM_ROOT` | Примусово задати корінь проєкту |
