# CLI

```
engram <команда> [опції]
```

| Команда | Що робить |
| --- | --- |
| `init` | Створює `.engram/`, підключає агентів, ставить skills, індексує репозиторій |
| `serve` (`mcp`) | Запускає MCP-сервер через stdio |
| `status` | Кількість за видами й статусами, остання активність |
| `summary [--full]` | Огляд проєкту |
| `context [завдання…]` | Друкує контекст-пакет, який отримає агент (`-b` бюджет, `-f` файли, `--raw`) |
| `remember <заголовок>` (`add`) | Зберігає запис (`-k` вид, `-c` текст, `-t` теги, `-f` файли, `-i` важливість, `-s` статус, `--supersedes id`) |
| `recall [запит…]` (`search`) | Шукає (`-k` види, `-t` теги, `-f` файли, `-a` разом із неактивними, `-n` ліміт, `--json`) |
| `show <id>` (`get`) | Один запис зі зв’язками (`--json`) |
| `link <from> <relation> <to>` | Зв’язує записи (`-n` нотатка) |
| `graph <id>` | Показує околицю в графі (`-d` глибина) |
| `why <тема…>` | Історія теми |
| `check <план…>` | Звіряє план із граблями (`-f` файли) |
| `forget <id>` | Архівує, а з `--hard` видаляє |
| `index` | Імпортує ADR і сигнали з git (`--no-adr`, `--no-git`) |
| `export` | `--format jsonl` або `md`, `-o file` |
| `import <file>` | Вливає JSONL-вивантаження |
| `sync` | Перечитує й начисто переписує `memories.jsonl` |
| `skills list` | Показує вбудовані skills |
| `skills install` | Копіює skills у `.claude/skills` (`--global`, `--dir`) |

## Опції `init`

| Опція | |
| --- | --- |
| `-a, --agent <список>` | `claude`, `cursor`, `agents-md`, `all`. За замовчуванням агенти визначаються самі. |
| `-p, --project <назва>` | Назва проєкту для оглядів |
| `--no-skills` | Не ставити skills |
| `--no-index` | Не сканувати ADR і історію git |

## Змінні оточення

| Змінна | |
| --- | --- |
| `ENGRAM_ROOT` | Примусово задає корінь проєкту |
