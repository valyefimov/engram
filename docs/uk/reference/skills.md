# Skills

У комплекті йде шість skills. У Claude Code вони копіюються в `.claude/skills/` і стають slash-командами. Інші MCP-клієнти отримують їх як MCP prompts.

| Skill | Коли агент його використовує |
| --- | --- |
| `remember-decision` | Ухвалено рішення або відхилено варіант; «запам’ятай це», «робимо так…» |
| `recall` | «Ми вже…?», «де ми обговорювали…?» або вхід у незнайому частину коду |
| `why-we-did-this` | «Чому X так влаштований?», «чому не Y?» або перед зміною усталеного патерну |
| `avoid-past-mistakes` | Перед рефакторингом, міграцією, заміною залежності або роботою з ризикованими файлами |
| `project-summary` | Онбординг, «введи в курс справи» або повернення після перерви |
| `session-handoff` | «Закруглюємося», «збережи прогрес» або кінець завдання |

## `remember-decision`

Записує рішення у фіксованій формі: контекст, рішення, чому, альтернативи, наслідки. Спершу він перевіряє, чи немає ранішого рішення, яке це замінює. Серйозно розглянуті альтернативи зберігаються як `rejected`-рішення й зв’язуються через `rejected_because`.

## `avoid-past-mistakes`

Формулює план і викликає `engram_check` з планом і файлами. Для кожного попередження вирішує, чи воно застосовне, і або виправляє план, або зупиняється й питає. Якщо щось усе ж пішло не так, записує нові граблі.

## Власний skill

Кожен skill лежить в окремій теці з файлом `SKILL.md`:

```markdown
---
name: release-checklist
description: Перед релізом згадати граблі й принципи, пов’язані з релізами.
---

1. Виклич `engram_recall` з `kinds: ["pitfall", "principle"]` і `tags: ["release"]`.
2. …
```

`$ARGUMENTS` замінюється тим, що користувач написав після команди.
