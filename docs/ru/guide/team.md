# Командная память

## Модель

- `.engram/memories.jsonl` — **источник истины**. Одна JSON-запись на строку, отсортировано по id: записи, связи, сессии и tombstones. Коммитьте его.
- `.engram/engram.db` — **локальный SQLite-индекс**, собирается из JSONL. В `.gitignore`.

Каждая запись зеркалируется в JSONL (атомарно: запись во временный файл и rename). При каждом открытии engram хэширует JSONL; если файл изменился с момента последней записи — `git pull`, merge, ручная правка — записи вливаются в локальный индекс.

## Правила слияния

- **Записи:** побеждает последний писавший, по `updatedAt`.
- **Tombstones** (жёсткие удаления) побеждают запись, на которую указывают.
- **Связи и сессии:** объединение.
- **Неразрешённые git-маркеры конфликта** в JSONL допускаются: обе стороны вливаются, файл перезаписывается начисто.

Файл отсортирован по случайным id, поэтому два человека, добавляющие записи, редко трогают соседние строки — большинство merge проходят без конфликтов.

## Ревью того, что выучил агент

Память можно ревьюить как код. Diff pull request'а показывает, какие решения и грабли добавились. Читаемая выгрузка:

```bash
engram export --format md -o docs/MEMORY.md
```

## Онбординг

Новый разработчик — или новый агент — спрашивает:

> Объясни архитектуру авторизации.

и получает реальную историю решений, а не догадки. `engram summary --full` даёт полную картину.

## Приватность

Память пишется для коллег. Инструкции сервера запрещают агентам сохранять секреты, учётные данные и персональные данные — но ревьюйте `memories.jsonl`, как любой закоммиченный файл. Чтобы память оставалась только на вашей машине, добавьте `.engram/memories.jsonl` в `.gitignore` или установите `"sync": { "jsonl": false }`.
