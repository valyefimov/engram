# CLI

```
engram <команда> [опции]
```

| Команда | Что делает |
| --- | --- |
| `init` | Создаёт `.engram/`, подключает агентов, ставит skills, индексирует репозиторий |
| `serve` (`mcp`) | Запускает MCP-сервер через stdio |
| `status` | Количество по видам и статусам, последняя активность |
| `summary [--full]` | Обзор проекта |
| `context [задача…]` | Контекст-пакет, который получит агент (`-b` бюджет, `-f` файлы, `--raw`) |
| `remember <заголовок>` (`add`) | Сохранить запись (`-k` вид, `-c` текст, `-t` теги, `-f` файлы, `-i` важность, `-s` статус, `--supersedes id`) |
| `recall [запрос…]` (`search`) | Поиск (`-k` виды, `-t` теги, `-f` файлы, `-a` включая неактивные, `-n` лимит, `--json`) |
| `show <id>` (`get`) | Одна запись со связями (`--json`) |
| `link <from> <relation> <to>` | Связать записи (`-n` заметка) |
| `graph <id>` | Окрестность в графе (`-d` глубина) |
| `why <тема…>` | История темы |
| `check <план…>` | Проверить план на грабли (`-f` файлы) |
| `forget <id>` | Архивировать или `--hard` удалить |
| `index` | Импорт ADR и сигналов из git (`--no-adr`, `--no-git`) |
| `export` | `--format jsonl|md`, `-o file` |
| `import <file>` | Влить JSONL-выгрузку |
| `sync` | Перечитать и начисто переписать `memories.jsonl` |
| `skills list` | Встроенные skills |
| `skills install` | Скопировать skills в `.claude/skills` (`--global`, `--dir`) |

## Опции `init`

| Опция | |
| --- | --- |
| `-a, --agent <список>` | `claude`, `cursor`, `agents-md`, `all` (по умолчанию — автоопределение) |
| `-p, --project <имя>` | Имя проекта для обзоров |
| `--no-skills` | Не ставить skills |
| `--no-index` | Не сканировать ADR и git-историю |

## Переменные окружения

| Переменная | |
| --- | --- |
| `ENGRAM_ROOT` | Принудительно задать корень проекта |
