# Дорожня карта

Це плани. Терміни й обсяг можуть змінитися.

## 1.0: що є зараз

- MCP-сервер з 14 інструментами, ресурсами, prompts та інструкціями для агента
- Сховище на SQLite і FTS5 без нативних залежностей, з обробкою дублікатів під час запису
- Граф знань з типізованими ребрами, лінією рішень, `why` і перевіркою граблів
- Компресор контексту з бюджетами токенів і передача сесій
- Імпорт ADR, а також hotspots і відкати з git
- Шість skills, CLI і синхронізація через JSONL з tombstones, зручна для git
- Документація англійською, російською та українською

## 1.1: розуміння коду

- Індексатор, що розбирає код (tree-sitter або ts-morph): символи як вузли `file`, пов’язані з рішеннями
- Необов’язкові локальні ембедінги (bge або nomic) для гібридного пошуку за змістом і за словами
- Маршрутизація великих виводів інструментів
- Пошук застарілих записів, чиї файли змінилися або зникли

## 1.2: команди

- Кілька проєктів і особиста пам’ять, спільна для них
- Синхронізація не лише через git, через необов’язковий сервер
- Веб-інтерфейс, щоб переглядати й редагувати граф

## 2.0

- Локальні ембедінги з коробки
- Налаштування для інших агентів однією командою
- Плагіни для власних індексаторів і видів записів
