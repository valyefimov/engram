# Skills

В комплекте идут шесть skills. В Claude Code они копируются в `.claude/skills/` и становятся slash-командами. Остальные MCP-клиенты получают их как MCP prompts.

| Skill | Когда агент его использует |
| --- | --- |
| `remember-decision` | Принято решение или отвергнут вариант; «запомни это», «делаем так…» |
| `recall` | «Мы уже…?», «где мы обсуждали…?» или вход в незнакомую часть кода |
| `why-we-did-this` | «Почему X так устроен?», «почему не Y?» или перед изменением устоявшегося паттерна |
| `avoid-past-mistakes` | Перед рефакторингом, миграцией, заменой зависимости или работой с рискованными файлами |
| `project-summary` | Онбординг, «введи в курс дела» или возвращение после перерыва |
| `session-handoff` | «Закругляемся», «сохрани прогресс» или конец задачи |

## `remember-decision`

Записывает решение в фиксированной форме: контекст, решение, почему, альтернативы, последствия. Сначала он проверяет, нет ли более раннего решения, которое это заменяет. Серьёзно рассмотренные альтернативы сохраняются как `rejected`-решения и связываются через `rejected_because`.

## `avoid-past-mistakes`

Формулирует план и вызывает `engram_check` с планом и файлами. Для каждого предупреждения решает, применимо ли оно, и либо правит план, либо останавливается и спрашивает. Если что-то всё же пошло не так, записывает новые грабли.

## Свой skill

Каждый skill лежит в отдельной папке с файлом `SKILL.md`:

```markdown
---
name: release-checklist
description: Перед релизом вспомнить грабли и принципы, связанные с релизами.
---

1. Вызови `engram_recall` с `kinds: ["pitfall", "principle"]` и `tags: ["release"]`.
2. …
```

`$ARGUMENTS` заменяется тем, что пользователь написал после команды.
