# Дорожная карта

## v1.0 — память, которая работает ✅

- MCP-сервер: 14 инструментов, ресурсы, prompts, инструкции сервера
- Хранилище на SQLite + FTS5 (без нативных зависимостей), дедупликация
- Граф знаний с типизированными рёбрами, линией решений, `why`, проверкой граблей
- Компрессор контекста с бюджетом токенов, передача сессий
- Импорт ADR, hotspots и откаты из git
- 6 skills, CLI, git-friendly синхронизация через JSONL с tombstones
- Документация на английском, русском и украинском

## v1.1 — понимание кода

- Индексатор кода (tree-sitter / ts-morph): символы как узлы `file`, связанные с решениями
- Опциональные локальные эмбеддинги (bge / nomic) для гибридного поиска
- Автоматическая маршрутизация больших выводов инструментов
- Гигиена памяти: устаревшие записи, чьи файлы изменились или исчезли

## v1.2 — команды

- Несколько проектов и личная кросс-проектная память
- Синхронизация не только через git (опциональный сервер)
- Веб-UI для просмотра и редактирования графа

## v2.0

- Локальные эмбеддинги из коробки
- Интеграции с популярными агентами одной командой
- Плагинная система для своих индексаторов и видов записей
